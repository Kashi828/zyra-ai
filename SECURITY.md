# Security Policy

ZYRA AI is designed as a local-first agent with explicit authorization boundaries.

## Reporting

Do not publish sensitive security details, credentials, private keys, or exploit material
in public issues. Report security vulnerabilities privately to the repository maintainers.

## Local data

Local session state, databases, credentials, and machine-specific configuration must
remain outside source control.

## Agent safety

New tools should use the existing permission, policy, authorization, confirmation,
emergency-stop, and audit mechanisms.
