# ZYRA AI — Android Beta

This module is a real Gradle Android application around the existing secure session, enrollment, transfer, and realtime transport code.

Build with Gradle 9.5.0 and JDK 17. The project uses Android Gradle Plugin 9.3.1 and Kotlin 2.4.20.

The CI beta build produces an installable debug APK for tester distribution. A signed release/AAB build can be enabled later with repository signing secrets.
