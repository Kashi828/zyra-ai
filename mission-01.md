# Mission 01 — Build Sequence

1. Initialize desktop shell.
2. Add agent API.
3. Add tool registry.
4. Implement safe file/application tools.
5. Add policy + permissions.
6. Add audit log + emergency stop.
7. Add browser tool behind the same policy layer.
8. Add Android pairing protocol.
9. Add background task/event engine.

## Safety rule

Any capability that can affect external systems, modify important data, expose sensitive information, or create significant side effects must pass explicit policy checks and, where appropriate, user confirmation.
